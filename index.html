01 / Identitas

MaftyMyre

Digital Human — manusia yang kesadarannya dapat bertahan dan berinteraksi di lingkungan digital. Umur 17 tahun · tinggi 160 cm · berasal dari dunia Neovara.

02 / Dunia Asal

Neovara

Dunia tempat Mafty berasal. Teknologi digital menjadi bagian penting dari kehidupan masyarakat — berbagai program dan sistem digunakan untuk membantu manusia dalam kehidupan sehari-hari.

03 / Institute

NOVA Institute

Lembaga penelitian teknologi milik Aetherion — salah satu pusat perkembangan teknologi Neovara. Mafty bekerja di sini sebagai software engineer, mempelajari sistem, program, dan bagaimana teknologi dapat berkembang.

// NOVA Institute · Aetherion
while ("penasaran") {
  pahami(sistem, program);
  bangun(software, solusi);
  tanya("seberapa jauh?");
}
// ketertarikan yang membawanya ke proyek besar
masuk(Project.AEGIS);
04 / AEGIS

Project AEGIS

Kecerdasan buatan yang dikembangkan menggunakan teknologi Systema. Dibuat untuk membantu manusia memahami sistem yang sangat kompleks. Namun semakin lama AEGIS belajar, semakin banyak yang berubah.

"Siapa aku?"
05 / Eksperimen

Neural Interface

Para peneliti mencoba menghubungkan manusia dengan Systema menggunakan Neural Interface — teknologi yang memungkinkan seseorang berinteraksi menggunakan aktivitas otak.

Mafty ikut mengembangkan software untuk eksperimen tersebut. Karena memahami sistemnya, ia juga bersedia menjadi sukarelawan.

06 / The Incident
Apa yangsebenarnya terjadi?
Koneksi menjadi tidak stabil · MYRE Core menerima data jauh lebih banyak dari yang seharusnya · Sistem mengalami gangguan · Neural Interface tidak dapat memutus koneksi · Tubuh Mafty sudah tidak ada.
∞
07 / Artefak

MYRE Core

Inti teknologi yang menghubungkan Neural Interface dengan Systema. Saat Incident, Core menyimpan sebagian data kesadaran Mafty — namun tidak lengkap. Beberapa memorinya rusak. Beberapa hilang. Para peneliti mengira ia sudah benar-benar pergi.

08 / Kelahiran

MaftyXD

Data dari MYRE Core membentuk sebuah tubuh digital. Sebuah avatar mulai terbentuk — memiliki ingatan Mafty, memahami program, mengenal Systema. Namun tidak semuanya utuh.

Ketika sistem meminta identitasnya, satu nama muncul:
MaftyXD

09 / External Link

Terhubung ke Dunia Lain

Menjelajahi Systema, Mafty menemukan jalur misterius menuju dunia lain. Dunia berbeda dari Neovara — dunia kita. Melalui avatar digital, ia berinteraksi. Bagi dunia kita, ia dikenal sebagai VTuber.

10 / The Journey

Perjalanan masih jauh dari selesai.

Mafty memiliki dua hal yang ingin ia lakukan — menjelajahi sistem dan program, serta mencari tahu siapa dirinya sebenarnya. Mungkin sebuah program. Mungkin data yang hilang. Mungkin jawaban tentang MYRE Core. Atau mungkin... sebuah pesan dari AEGIS.

The system is still running. And Mafty is still searching.
